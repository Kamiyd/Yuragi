# B 轨：不能跑命令时手写抖动的六条习语

滤镜在做三件事：沿法线叠低频正弦、收笔越位、转角收紧切线。翻译成手写
（数值按 **64 网格**）：

| 滤镜在做什么 | 手写时怎么做 |
|---|---|
| 沿法线叠低频噪声 | 直笔画**不要用 `L`**，用 `C`：中段往法线方向偏 **0.4–0.7**。长笔画偏两次，方向相反 |
| 幅度按弧长分档 | 短笔画（点、短撇，弧长 < 13）偏 **0.25**；中等（13–30）偏 **0.45**；长（> 30）偏 **0.6** |
| 收笔越位 | **拙趣汉字不做**：两头不探出，端点正好落在另一笔上（喜茶的字不出头；对应字库的 `over: 0`） |
| 转角处压低抖动 | 折角前后各留一小段规矩的直线，别在折角上弯 |
| 折角写尖 | 直接 `L` 折过去；钩短，3–5 个单位（骨架怎么写拙见 `glyphs.md`「骨架要拙」） |
| 逐字不一样 | 先按字定大小（复杂字大、简单字小，窄字窄、扁字扁，见 `glyphs.md`「字有大有小」），再逐字 ±9%，相邻两个至少差 3.5% |

最后一条最要紧：**不摇大小就是一版字帖**，线抖得再像也没用。

**A 轨下这张表一条都不用管** —— 骨架画规矩了，滤镜全包。

B 轨额外一条：**一整行一口气画完。** 隔几轮再补的那几个字一定不是同一只手。
